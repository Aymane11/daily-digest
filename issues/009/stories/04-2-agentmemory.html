AgentMemory

Persistent memory server for AI coding agents with 95.2% R@5 retrieval

Open-source MCP server that captures tool calls, prompts, and session state as searchable semantic memories

MAY 11 2026

★ WHAT IT IS

AgentMemory is a persistent memory server for AI coding agents. It automatically captures tool calls, prompts, and session state via 12 auto-capture hooks, storing them as searchable semantic memories. Uses hybrid BM25 + vector + knowledge graph retrieval with an on-device reranker. Ships as an MCP server + REST API + real-time viewer. Works with Claude Code, Cursor, Gemini CLI, OpenCode, Codex, Cline, and any MCP client.

¶ 01 WHY · IT · MATTERS

The "memory wall" is the #1 unsolved problem for coding agents — every session starts fresh, forcing agents to re-discover context. AgentMemory hits 95.2% R@5 on LongMemEval-S, 27 points above Mem0 (68.5%). Claims 92% token reduction vs. re-pasting full context. This is the first open-source memory solution with benchmark-backed performance for coding agents.

¶ 02 HOW · TO · TRY · IT ~20 MIN
01

npx @agentmemory/agentmemory

02

Open the viewer at http://localhost:3113

03

In a second terminal: npx @agentmemory/agentmemory demo (seeds 3 test sessions)

04

Add to Claude Code MCP config: {"mcpServers":{"agentmemory":{"command":"npx","args":["-y","@agentmemory/mcp"]}}}

05

Ask Claude Code to "remember this function's location" then start a new session and ask it to recall

¶ 03 WHAT · TO · OBSERVE

Open the viewer at localhost:3113 — see live observation stream showing every agent action being captured. The session explorer shows past sessions. The knowledge graph visualization shows relationships between concepts discovered across sessions. With the demo seed, you should see 3 pre-populated sessions with memories, tool calls, and semantic relationships.
