HiDream-O1-Image

Open-source 8B image generation model that works in pixel space — no VAE needed

Ranks #8 on Text-to-Image Arena, highest-ranked open-weights model, MIT licensed

MAY 11 2026

★ WHAT IT IS

HiDream-O1-Image is an 8B-parameter open-source image generation model built on a Pixel-level Unified Transformer (UiT). Unlike standard diffusion models, it has no external VAE or disjoint text encoder — it works directly in pixel space. Supports text-to-image, instruction-based editing, and subject-driven personalization at up to 2048x2048.

¶ 01 WHY · IT · MATTERS

It debuts at #8 on the Artificial Analysis Text-to-Image Arena — the highest-ranked open-weights model on the leaderboard. Its "Reasoning-Driven Prompt Agent" pre-thinks layout and text before generation, solving a chronic failure mode in open-source image models. MIT licensed for full commercial use. This is the first open model to truly compete with closed-source image generators on prompt adherence and text rendering.

¶ 02 HOW · TO · TRY · IT ~30 MIN
01

git clone https://github.com/HiDream-ai/HiDream-O1-Image.git

02

cd HiDream-O1-Image && pip install -r requirements.txt

03

Download weights from Hugging Face: huggingface-cli download HiDream-ai/HiDream-O1-Image --local-dir ./HiDream-O1-Image

04

python inference.py --model_path ./HiDream-O1-Image --prompt "A cat wearing an astronaut helmet on Mars, digital art" --output_image cat-astronaut.png

05

Try the Dev variant: python inference.py --variant dev --steps 28 --prompt "Your prompt here"

¶ 03 WHAT · TO · OBSERVE

The 50-step generation produces a 2048x2048 image. The Dev variant does 28 steps. Compare prompt adherence against SD3.5 or Flux — particularly text rendering in images (signs, labels). The Reasoning-Driven Prompt Agent should correctly handle complex spatial relationships like "a red cube on top of a blue sphere."
