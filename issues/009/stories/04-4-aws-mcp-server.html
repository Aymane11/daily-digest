AWS MCP Server + Agent Toolkit

First managed MCP server from a major cloud provider — now GA

AI coding agents get IAM-guarded access to all 15,000+ AWS API operations with 40+ pre-built agent skills

MAY 11 2026

★ WHAT IT IS

The AWS MCP Server (now GA) gives AI coding agents secure, auditable access to any AWS service via IAM-based guardrails, CloudWatch monitoring, and CloudTrail logging. Ships with 40+ "agent skills" — validated procedures for CloudFormation, data pipelines, serverless, containers, and more. Three plugins: AWS Core, AWS Data Analytics, AWS Agents. Part of the Agent Toolkit for AWS which also includes WorkSpaces for AI agents (preview) and Bedrock AgentCore payment capabilities.

¶ 01 WHY · IT · MATTERS

This is the first managed MCP server from a major cloud provider. Agents can call any AWS API through a single tool, including file uploads and long-running operations. Sandboxed Python execution means agents can run multi-step operations without filesystem access. Skills are pre-evaluated for accuracy. Free to use — pay only for AWS resources consumed.

¶ 02 HOW · TO · TRY · IT ~30 MIN
01

In Claude Code, run: mcp add aws --npx @aws/agent-toolkit-mcp

02

Ensure your AWS credentials are configured (AWS_PROFILE or environment variables with sufficient IAM permissions)

03

Ask: "describe my EC2 instances in us-east-1" — the agent should call the AWS API directly

04

Ask: "create an S3 bucket named my-agent-test-bucket-{random} with versioning enabled"

05

Review the CloudTrail logs for API calls made by the agent

¶ 03 WHAT · TO · OBSERVE

The agent should execute AWS API calls directly rather than generating boto3 code for you to run. Each call is IAM-authorized and logged to CloudTrail. With sandboxed execution, the agent can run multi-step scripts safely. Try the data analytics plugin: ask the agent to query an Athena table or describe a Glue job.
