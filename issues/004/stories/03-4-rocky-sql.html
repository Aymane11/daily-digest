Rocky: Rust-written SQL control plane with Git-style branching, column lineage, and compile-time data contracts

Rocky is an open-source (Apache 2.0) Rust-based control plane for data warehouse pipelines. It sits above existing warehouses—Databricks, Snowflake, BigQuery, DuckDB—rather than replacing them, handling DAG orchestration, governance, and safety guarantees. The headline features are named branches (isolated pipeline testing with blast-radius analysis before merging), compiler-time column lineage (traces individual columns from downstream facts back to source seeds with no runtime overhead), and compile-time data contracts (validates required columns and types before the job runs). It also ships schema drift detection, per-model cost attribution, and AI-assisted model generation that type-checks suggestions before deployment. A local playground runs on DuckDB with no credentials required. Built by Hugo Correia; adapters for Databricks (GA), Snowflake (Beta), BigQuery (Beta) are available.

WHAT TO WATCH

Try the playground in under five minutes: curl -fsSL https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.sh | bash && rocky playground my-first-project && cd my-first-project && rocky compile && rocky test && rocky run. Evaluate whether compile-time contract enforcement catches the schema drift issues that currently reach you as runtime failures in production.
