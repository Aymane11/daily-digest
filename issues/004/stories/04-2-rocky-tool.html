Rocky

A Rust-written SQL control plane that adds Git-style branching, compile-time contracts, and column lineage to your existing data warehouse

WHY IT'S WORTH TRYING

Rocky solves the governance gap that dbt and Airflow leave open: schema drift that only surfaces at runtime, lineage that stops at the table level, and pipeline changes that are risky to test in production. It works alongside your existing warehouse rather than replacing it.

The column lineage feature is the most technically distinct element: Rocky traces individual columns from downstream fact tables back to source seeds at compile time, with zero runtime overhead. If you have ever spent hours debugging a broken metric because an upstream column was silently renamed, this is the tool that would have caught it before the job ran.

GETTING STARTED (ZERO SETUP)

The local playground runs on DuckDB — no warehouse credentials, no cloud account:

curl -fsSL https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.sh | bash
rocky playground my-first-project
cd my-first-project
rocky compile   # validates contracts, checks lineage
rocky test      # runs data quality assertions
rocky run       # executes the pipeline on DuckDB

The compile step is where Rocky's value shows: it catches type mismatches, missing required columns, and broken lineage references before any data moves.

CONNECTING TO YOUR WAREHOUSE

Add a profile to rocky.toml:

[profile.production]
warehouse = "snowflake"
account   = "your-account.snowflakecomputing.com"
database  = "analytics"
schema    = "core"
role      = "transformer"

Then run rocky compile --profile production. Databricks is GA; Snowflake and BigQuery are in beta.

WHAT TO OBSERVE

  • Compile output should list every column's lineage path from source to destination — verify it matches your mental model
  • Introduce a deliberate type mismatch in a model and confirm Rocky catches it at compile time, not runtime
  • Create a branch (rocky branch create experiment), modify a model, and check the blast-radius report before merging
  • Check per-model cost attribution after a production run — compare against your warehouse's native cost reporting

NOT A REPLACEMENT FOR

Rocky complements dbt and Airflow — it is not a data warehouse, a Fivetran alternative, or a dbt Cloud competitor. It adds a governance and safety layer on top of your existing stack.
