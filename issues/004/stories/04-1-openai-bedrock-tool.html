OpenAI on AWS Bedrock

GPT-5.5, Codex, and Bedrock Managed Agents — now accessible via your existing AWS credentials without switching cloud providers

WHY IT'S WORTH TRYING

If your organisation runs workloads on AWS and has evaluated OpenAI models but avoided the complexity of managing a separate API key, billing relationship, and VPC configuration, Bedrock eliminates those barriers. You get GPT-5.5 through the same IAM roles, PrivateLink endpoints, and CloudTrail audit logs you already use for Anthropic Claude or Meta Llama models on Bedrock.

The Managed Agents product is the more interesting addition: it packages the OpenAI agent harness (model + runtime + tool-calling steering) as a fully managed AWS service, so you can deploy production agent workflows without building your own orchestration layer on top of raw API calls.

WHAT PROBLEM IT SOLVES

  • Eliminates the need to split cloud infrastructure between Azure (OpenAI) and AWS (everything else)
  • Inherits enterprise controls — IAM, PrivateLink, data residency, CloudTrail — that teams have already configured
  • Removes a separate OpenAI billing relationship for teams standardised on AWS Cost Explorer
  • Provides a managed agent runtime that handles long-running tasks, tool-calling, and retries without custom scaffolding

GETTING STARTED (LIMITED PREVIEW)

Step 1: Request limited preview access via the AWS Bedrock console → Model access → OpenAI models. As of April 29, 2026, access is gated.

Step 2: Once approved, authenticate with your existing AWS credentials. No OpenAI API key is required.

Step 3: Call GPT-5.5 via the Bedrock Converse API using the model ID openai.gpt-5-5-v1:

import boto3
client = boto3.client("bedrock-runtime", region_name="us-east-1")

response = client.converse(
    modelId="openai.gpt-5-5-v1",
    messages=[{"role": "user", "content": [{"text": "Explain KV cache compression"}]}]
)
print(response["output"]["message"]["content"][0]["text"])

Step 4 (Codex): Install the Codex CLI and point it at Bedrock. Authenticate via aws sso login — no separate API key needed. Run codex --backend bedrock "refactor auth.py to use async/await".

WHAT TO OBSERVE

  • Latency vs. direct OpenAI API — Trainium-backed inference may differ from GPU-hosted models; measure p50 and p99
  • CloudTrail logs should show bedrock:InvokeModel events with the OpenAI model ID — confirm your audit trail is intact
  • Pricing: confirm Bedrock's per-token rate matches or is within acceptable margin of OpenAI's direct $5/$30 per million tokens (input/output)
  • Data residency: verify requests stay within your configured AWS region by checking VPC flow logs

AT A GLANCE

Status: Limited preview (request access)
Models: GPT-5.5, Codex
Auth: AWS IAM (no OpenAI key)
Networking: PrivateLink supported
Pricing: ~$5/$30 per 1M tokens
Free tier: Standard Bedrock free tier applies during preview

ACCESS LIMITS

Limited preview only — not generally available as of April 29, 2026. Request access via Bedrock console. Managed Agents is a separate gated preview from model access.

FREE ALTERNATIVE

Anthropic Claude 3.5 Haiku and Meta Llama 3.3 70B are available on Bedrock with no preview gate and lower per-token costs for latency-sensitive workloads.
