HISTORY OPEN SOURCE

Before GitHub: what open-source development looked like when developers owned their own infrastructure

Armin Ronacher (Flask, Jinja2, Click) published a personal history of open source before GitHub's 2008 arrival. He describes a "much smaller world" where projects lived on self-hosted Trac installations, Subversion repositories, and mailing lists—and where reputation mattered "in a very direct way" because you needed to know a maintainer's track record before depending on their code. Dependency selection was deliberate; vendoring was common. GitHub eliminated the barriers to publishing and discovering code—democratizing participation while also concentrating open source around a single company and triggering the micro-dependency explosion. The post collected 460 HN points and 134 comments in the context of Ghostty's announced GitHub departure.

WHAT TO WATCH

Ask: if GitHub disappeared tomorrow, could your team recover all code, CI history, and issue context in under 48 hours? Evaluate your backup posture against your actual blast radius: git remote mirrors are not the same as issue and Actions data. Check whether your GitHub dependency has grown past what a reasonable backup strategy can cover.
