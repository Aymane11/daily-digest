OpenAI lands GPT-5.5, Codex, and Managed Agents on Amazon Bedrock one day after Microsoft exclusivity ends

WED 29 APR 2026 · 5 MIN READ · BY EDITORIAL TEAM

TL;DR

OpenAI announced on April 28, 2026 that GPT-5.5, Codex, and a new Bedrock Managed Agents product are available in limited preview on AWS. The move comes one day after OpenAI and Microsoft restructured their exclusive deal, and fulfils OpenAI's obligation tied to its $50 billion AWS financing round. Enterprise customers can now access OpenAI models through existing AWS IAM credentials, PrivateLink, and CloudTrail without switching cloud providers.

¶01 · WHAT HAPPENED

At an AWS event in San Francisco on April 28, OpenAI CEO Sam Altman and AWS CEO Matt Garman announced three integrated products launching in limited preview on Amazon Bedrock:

  • GPT-5.5 on Bedrock — OpenAI's current frontier model, accessible via the same Bedrock API surface used for Anthropic and Meta models, inheriting IAM, PrivateLink, guardrails, encryption, and CloudTrail logging.
  • Codex on Bedrock — OpenAI's coding agent authenticates via AWS credentials and runs through Bedrock via the Codex CLI, desktop app, and VS Code extension. No separate OpenAI account required.
  • Bedrock Managed Agents powered by OpenAI — packages the OpenAI agent harness (model + runtime + steering) as a fully managed AWS service, targeting production agent deployments with minimal infrastructure overhead.

The timing is deliberate: on April 27, OpenAI and Microsoft restructured their 2019 exclusive agreement into a non-exclusive preferred-provider arrangement. That change, combined with a $50 billion AWS financing commitment that required OpenAI to use up to two gigawatts of Amazon's Trainium accelerators, unblocked the Bedrock integration.

¶02 · WHY IT MATTERS

The primary effect is distribution, not capability. GPT-5.5's benchmark numbers haven't changed; what changed is that AWS's existing enterprise customer base—companies that have spent years building on Bedrock's IAM roles, VPC isolation, and compliance audit trails—can now access OpenAI models without migrating or splitting their infrastructure.

Altman described pent-up demand as "astronomical." The deal reframes the AI platform competition from a two-sided battle (OpenAI via Azure vs. Anthropic via AWS) into a model-agnostic marketplace where AWS acts as a distribution layer rather than an exclusive partner. Anthropic's Claude models remain on Bedrock alongside OpenAI's, meaning enterprise buyers can evaluate both through the same interface.

The Managed Agents product is the more structurally significant piece. Rather than forcing customers to choose between OpenAI's hosted agent runtime and AWS infrastructure, it bundles both. This positions Bedrock Managed Agents as a production agent deployment surface that abstracts model provider selection.

¶03 · WHAT TO WATCH

Check if you qualify for limited preview. Bedrock Managed Agents powered by OpenAI is gated; request access at the AWS console and benchmark latency against your current Anthropic or Azure endpoint before committing. Trainium-backed inference may have different latency profiles than GPU-hosted OpenAI models.

Track pricing parity. OpenAI's direct API prices GPT-5.5 at $5/$30 per million tokens (input/output). AWS typically adds a small margin for managed services; confirm the Bedrock price sheet before routing production workloads.

Watch the Google Cloud move. OpenAI and Microsoft's restructuring opens the door to a Google Cloud integration. If that closes, every major hyperscaler will offer OpenAI models, and the competitive question shifts to which cloud's enterprise integration layer is most complete.
