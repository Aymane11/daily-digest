Zyphra releases Zaya-1, a voice-native medical AI built to run on-device

Zyphra, a Palo Alto AI lab, released Zaya-1 on May 6 — a 2.7-billion-parameter model trained end-to-end on audio and text, designed for real-time clinical conversations without routing speech through a transcription step first. It runs on-device (including smartphones), supports 14 languages, and is available via API and SDK under a research license.

Unlike voice-enabled LLMs that transcribe audio to text then call a language model, Zaya-1 processes raw speech waveforms directly, preserving prosodic cues — tone, pace, hesitation — that carry clinical meaning. Zyphra claims it matches GPT-4o-class accuracy on medical benchmarks while running locally, which eliminates the cloud-latency and data-residency concerns that block many healthcare deployments. The model is specifically tuned for clinical dialogue: patient intake, triage questions, and symptom history — not general-purpose voice assistance.

What to watch

  • Try the Zaya-1 API on a synthetic patient intake script and measure first-token latency vs. a transcribe-then-LLM pipeline — the on-device claim is worth verifying against your target device class.
  • Check whether Zyphra publishes HIPAA-compliance documentation before evaluating for any production clinical workflow.
