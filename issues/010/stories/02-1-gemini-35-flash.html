01 CONTEXT

Google I/O 2026 bet: the next wave of AI is agent-first, not chatbot-first.

Gemini 3.5 Flash is Google’s first model designed around the premise that frontier reasoning and real-world action are inseparable. Previous Flash models traded quality for speed; 3.5 Flash is positioned as faster than any current frontier competitor while matching or exceeding those models on benchmark tasks that matter for agents: multi-step coding, long-horizon task completion, and tool-use reliability.

02 WHAT’S NEW

The model powers Gemini Spark — a personal agent running 24/7 that takes action on your behalf. It is the default model for Managed Agents in the Gemini API (one API call spins up an agent with tool use and code execution in an isolated Linux environment). CharXiv Reasoning score sits at 84.2%. The 3.5 Pro variant follows in June. Pricing details were not disclosed at launch.
