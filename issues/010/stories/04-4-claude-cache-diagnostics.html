Claude Cache Diagnostics

Visualise prompt cache hit rates, expiry patterns, and token savings across your Claude API calls

A lightweight open-source CLI and dashboard for teams that use Anthropic’s prompt caching — shows exactly where cache misses happen and how much they cost.

FRI 22 MAY 2026

★ WHAT IT IS

Claude Cache Diagnostics is an open-source tool from Anthropic that aggregates the cache_creation_input_tokens, cache_read_input_tokens, and input_tokens fields from the Claude API usage response and renders them as a time-series dashboard and a per-prompt breakdown. The CLI mode tails your application logs and computes a live hit-rate percentage; the dashboard mode ingests a CSV export from the Anthropic Console and produces an HTML report showing cache expiry gaps, the most expensive miss patterns, and projected monthly savings if hit rate reaches 80%.

¶ 01 WHY · IT · MATTERS

Prompt caching is one of the highest-leverage cost controls available for Claude API users — cache reads are priced at 10% of input token cost, so a well-structured application with an 80% hit rate reduces the effective input token price by 72%. The problem is that cache hit rates are invisible without instrumentation: the API returns the data per call, but no first-party tool aggregates it. Claude Cache Diagnostics fills that gap. The “expiry gap” analysis is particularly useful: it flags requests where a cache entry expired between calls because the interval exceeded the 5-minute TTL — a common silent cost driver in low-frequency batch pipelines.

¶ 02 HOW · TO · TRY · IT ~10 MIN
01

Install: pip install claude-cache-diagnostics. Requires Python 3.10+ and an Anthropic API key set as ANTHROPIC_API_KEY. The dashboard report mode also requires an Anthropic Console CSV export (Settings → Usage → Export).

02

Generate a dashboard: ccd report --input usage_export.csv --output report.html. Open report.html in a browser — the top section shows your overall hit rate and the cost delta vs. a 0% cache baseline for the export period.

03

For live monitoring, wrap your API calls with the ccd proxy: set ANTHROPIC_BASE_URL=http://localhost:8899 and run ccd proxy --port 8899. The proxy forwards all requests, intercepts usage fields, and displays a live TUI hit-rate counter. No data leaves your machine.

¶ 03 WHAT · TO · OBSERVE

The “expiry gap heatmap” in the dashboard report shows call intervals bucketed by seconds. Any bucket between 300 and 600 seconds with high volume is a strong signal that you are intermittently busting the 5-minute TTL — either add cache heartbeat calls or restructure your pipeline to keep intervals below 270 seconds. The “prompt fingerprint analysis” tab groups calls by the first 1,000 tokens of the system prompt: if you see many fingerprints with only a few calls each, your system prompts are not stable enough across requests to benefit from caching, and you should consolidate them.
