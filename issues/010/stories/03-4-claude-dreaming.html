AI AGENTS

Anthropic ships Claude “Dreaming” — async reasoning that continues after your session closes

A new API capability lets Claude Managed Agents perform extended background reasoning between sessions — picking up long tasks without forcing the user to stay connected.

BY · EDITORIAL TEAM · 2 MIN READ

★ WHAT HAPPENED

Anthropic introduced “Dreaming” as an API feature for Claude Managed Agents (Sonnet 4.5 and above). When a task is marked async: true in the agent API call, Claude continues reasoning in the background after the calling session terminates — executing tool calls, refining plans, and storing intermediate results to a durable context store. Users receive a webhook notification when the agent reaches a decision point requiring human input or completes the task entirely. Maximum dream duration is currently 4 hours; results are retrievable for 7 days.

¶ 01 WHY · IT · MATTERS

The biggest constraint on current agentic AI is the session boundary — every context window is an island, and any work that takes longer than a single call requires brittle orchestration hacks to resume. Dreaming moves the state-keeping burden off the developer and onto Anthropic’s infrastructure. For tasks like “research and write a 40-page due-diligence report” or “run a 200-file refactor and open PRs for each chunk,” this is the difference between a demo and a deployable product.

¶ 02 WHAT · TO · WATCH

Review Anthropic’s trust and safety disclosure on Dreaming carefully — the async model means the agent executes tool calls without a human in the loop for up to 4 hours, which requires explicit permission scoping. The webhook notification system is the kill switch: test it before deploying agents that write to production systems. Competitors at Google (Antigravity 2.0) and Microsoft (Agent 365) offer similar async capabilities — watch for pricing comparisons to emerge from developer benchmarks over the next two weeks.
