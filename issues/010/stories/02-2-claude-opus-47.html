¶ 01 WHAT · HAPPENED

Anthropic released Claude Opus 4.7 as the latest flagship in the claude-opus family. The model is a direct successor to Opus 4.6 with notable improvements across software engineering, vision, and instruction compliance. At launch, Opus 4.7 is state-of-the-art on the Finance Agent evaluation and posts a 13% resolution rate gain on SWE-bench variants compared to its predecessor. Vision now handles images up to 2,576 pixels on the long edge — more than three times the prior limit — enabling detailed analysis of high-resolution screenshots, technical diagrams, and financial charts.

xhigh New effort level between high and max gives API callers finer control over token allocation without jumping to uncapped reasoning depth
¶ 02 WHY · IT · MATTERS

Instruction-following in Opus 4.7 is more literal than prior versions: the model follows directives precisely, which means existing system prompts may need review to avoid unintended strictness. The Task Budgets public beta — which lets callers guide token allocation at a task level — directly addresses a common complaint with long-running agent loops: runaway costs. The Claude Code /ultrareview command opens dedicated code-review sessions that leverage the model’s improved vision and coding performance together.

“Opus 4.7 follows directives much more literally than predecessors — existing implementations may require prompt adjustments.”

— ANTHROPIC · RELEASE NOTES

¶ 03 WHAT · TO · WATCH

Migrate existing claude-opus-4-6 calls to claude-opus-4-7 and run your system prompt test suite before deploying to production — the stricter instruction-following will surface edge cases where your prompts relied on the model’s prior interpretive latitude. Evaluate Task Budgets in beta to cap agent costs on your longest-running workflows. Check whether the vision upgrade changes how your pipeline reads screenshots or diagrams.
