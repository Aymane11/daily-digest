Antigravity CLI

Local development and pipeline orchestration for Google’s managed agent platform

Test Antigravity agents locally before cloud deployment, run multi-step pipelines from a single YAML config, and stream agent logs in real time — all from the terminal.

FRI 22 MAY 2026

★ WHAT IT IS

Antigravity CLI is an open-source command-line tool released alongside Antigravity 2.0 at Google I/O 2026. It wraps the Antigravity REST API with a local development server that simulates the managed agent runtime, supports hot-reload of agent definitions, and provides a pipeline run command for orchestrating multi-agent YAML workflows. The CLI also includes a replay command that re-executes a captured agent trace from a JSON log — useful for debugging non-deterministic tool call sequences.

¶ 01 WHY · IT · MATTERS

The biggest friction point in agentic development is the edit-deploy-test loop: cloud agent platforms typically require a full deploy cycle to test changes, which can take minutes per iteration. The Antigravity CLI local server drops that to sub-second hot-reload. The replay command addresses the second biggest pain point — agents that fail intermittently due to model variance are nearly impossible to debug without the ability to re-run an exact trace. These two features together meaningfully close the gap between local development ergonomics and cloud agent deployment.

¶ 02 HOW · TO · TRY · IT ~10 MIN
01

Install: pip install antigravity-cli (Python 3.11+) or brew install antigravity-cli on macOS. Authenticate with antigravity auth login — this stores an OAuth token in your keychain.

02

Scaffold a new agent: antigravity init my-agent. This creates agent.yaml (definition), tools/ (Python tool handlers), and a tests/ directory with one example trace.

03

Run locally: antigravity serve --watch. Send a test message via antigravity chat "summarise my last 10 emails" and watch the tool call stream in your terminal. Edit agent.yaml and observe hot-reload within 500ms.

04

Replay a trace: antigravity replay --trace .antigravity/logs/2026-05-22T10-31-00.json. Compare the replayed output to the original and use --inject-tool-output to override specific tool responses for isolated debugging.

¶ 03 WHAT · TO · OBSERVE

Pay attention to the token count shown in the local serve output — the CLI renders per-turn context growth, which makes it easy to spot agents that are accumulating context faster than expected. The 1M-token ceiling of Antigravity 2.0 is not free: at $0.10/1M input tokens the maths works until you have many users running long sessions. The CLI’s cost estimator flag (--estimate-cost) runs a dry simulation before you deploy to production.
