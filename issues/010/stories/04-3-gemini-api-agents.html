Gemini API Managed Agents

Stateful, long-running agents over Gemini models with built-in session persistence and tool execution

Google’s answer to the OpenAI Assistants API — backed by Gemini 3.5 Flash, with 1M-token sessions, MCP-compatible tool definitions, and free-tier access at 100 RPM.

FRI 22 MAY 2026

★ WHAT IT IS

Gemini API Managed Agents is the programmatic access layer for Antigravity 2.0 — a REST and Python SDK API that lets you create, run, and manage stateful agents backed by Gemini 3.5 Flash (or Pro 2.0 for higher-tier accounts). Agents retain session state between calls via a server-managed context store, support MCP-compatible tool definitions via JSON Schema, and can be configured with up to 10 built-in Google integrations (Gmail, Drive, etc.) or custom tools. The Python SDK wraps the REST API with a streaming interface and an async client for webhook-based long-running tasks.

¶ 01 WHY · IT · MATTERS

The 1M-token context window is the headline, but the MCP-compatible tool format is the quiet structural advantage: if you already have MCP tool definitions for another platform (Claude, OpenAI), they port to Gemini Managed Agents with minimal modification. This reduces the cost of multi-provider agent strategies — you can benchmark the same agent against Gemini and Claude without rewriting tool definitions. The 100 RPM free tier is also the most generous in the managed agents space by a factor of roughly 7× compared to OpenAI’s Assistants free tier.

¶ 02 HOW · TO · TRY · IT ~15 MIN
01

Get an API key at aistudio.google.com (free tier, no billing required). Install: pip install google-generativeai>=2.0. The Managed Agents API is in the google.generativeai.agents module.

02

Create an agent: define a system prompt and at least one tool as a JSON Schema dict. Call client.agents.create(model="gemini-3.5-flash", system_prompt="...", tools=[...]) — this returns an agent_id you reuse across sessions.

03

Run a session: session = client.agents.run(agent_id, user_message="..."). Tool calls are streamed back as ToolCallEvent objects — execute them in your code and return results with session.submit_tool_output(). The session persists until you call session.end().

¶ 03 WHAT · TO · OBSERVE

Watch the context_tokens_used field returned in every session response — with 1M-token capacity it is easy to miss runaway context growth until a session hits the ceiling. The built-in Google integrations require an OAuth consent screen even for your own account; budget 20 minutes for the first-time setup. Compare the tool call latency to equivalent Claude and OpenAI agent benchmarks: Gemini 3.5 Flash’s 4× output speed should show up measurably in multi-step tool call sequences.
