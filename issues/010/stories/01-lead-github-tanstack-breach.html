05WHAT IT MEANS
3 TAKEAWAYS · LINKS
01

Every developer credential is a supply chain attack surface

The worm did not exploit a zero-day. It stole credentials from developers who installed a legitimately-published, widely-trusted extension. Audit every VS Code extension you run; check that none is version 18.95.0 of Nx Console. Remove what you do not actively need.

02

Claude Code configs and 1Password vaults were explicitly targeted

The credential stealer pulled Claude Code configurations, 1Password vault data, and cloud provider tokens in a single sweep. If you ran Nx Console in May, rotate your Anthropic API key, GitHub token, AWS access key, and npm publish token today.

03

Self-replicating supply chain attacks will keep expanding the blast radius

Mini Shai-Hulud is worm-like: each stolen CI/CD credential becomes a launch pad for more infected packages. GitHub, OpenAI, and Mistral AI are confirmed; others are likely. Watch for unexpected package version bumps in TanStack’s ecosystem and your own indirect dependencies.

§ 03 · WHAT TO WATCH

Check your installed VS Code extensions list right now: if Nx Console 18.95.0 appears in your history, rotate every credential that machine held. Watch npm for unexpected patch releases from any TanStack or Nx-adjacent package. Evaluate whether your CI/CD pipelines reference developer-side token stores that a worm could harvest without triggering a build failure. Ask your security team whether the 6,000 activation count includes any corporate machines.
