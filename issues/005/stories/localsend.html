APP OPEN SOURCE

LocalSend

Open-source cross-platform AirDrop alternative

BY · HACKER NEWS · 3 MIN READ

★ WHAT IT DOES

LocalSend is an open-source app that lets you send files between devices on the same network without internet. It works across platforms (Windows, macOS, Linux, iOS, Android), making it a true cross-platform AirDrop alternative. The app garnered 900+ points on Hacker News.

¶ 01 WHY TRY IT

Works across all platforms including mixed environments (e.g., Windows to iPhone). No internet required, works on local networks. Free and open source with no tracking or ads.

¶ 02 WHAT · TO · OBSERVE

Test transfer speeds on your local network. Verify it works between your specific device types. Check if it works behind VPNs or on enterprise networks.

HANDS-ON · TRY IT

1. Install on all devices:

# macOS
brew install localsend

# Windows (winget)
winget install LocalSend.LocalSend

# Linux (AUR)
yay -S localsend

2. Open app on both devices, they'll auto-discover

ACCESS · NOTES

Completely free. Open source on GitHub. No account required, no data collection. Available for iOS, Android, Windows, macOS, and Linux.
