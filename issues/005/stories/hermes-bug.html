BUG BILLING

HERMES.md bug routes Anthropic API requests to extra billing

GitHub issue shows file causes routing to metered endpoints

BY · HACKER NEWS · 2 MIN READ

★ WHAT HAPPENED

A bug in Claude Code causes API requests to route to metered endpoints when a file named HERMES.md exists in the project. The issue garnered 1,000+ points on Hacker News. Anthropic has acknowledged the bug and is working on a fix.

¶ 01 WHY · IT · MATTERS

Developers with HERMES.md files in their projects may have incurred unexpected API charges. The bug went unnoticed for some time, potentially affecting many users.

¶ 02 WHAT · TO · WATCH

Check your projects for HERMES.md files and review recent API bills. Rename the file temporarily if needed until the fix is released. Monitor the GitHub issue for updates.
