DEVTOOL MCP

ToolMesh

Turn REST APIs into MCP tools via declarative YAML

BY · HACKER NEWS · 3 MIN READ

★ WHAT IT DOES

ToolMesh converts any REST API into an MCP (Model Context Protocol) tool using simple YAML configuration. Instead of writing code to wrap APIs, you describe them declaratively and ToolMesh handles the rest.

¶ 01 WHY TRY IT

If you use Claude, Cursor, or other AI assistants with MCP, this tool lets you quickly add any REST API as an available tool without writing wrapper code. Useful for integrating internal APIs into AI workflows.

¶ 02 WHAT · TO · OBSERVE

Check if your internal APIs can be quickly exposed to AI assistants. Test the YAML schema to ensure it handles your API's authentication and parameter requirements.

HANDS-ON · TRY IT

1. Install:

npm install -g toolmesh

2. Create config.yaml:

tools:
  - name: github-create-issue
    endpoint: https://api.github.com/repos/{owner}/{repo}/issues
    method: POST
    params:
      - name: title
        type: string
      - name: body
        type: string

3. Run: toolmesh serve config.yaml

ACCESS · NOTES

Open source on GitHub. Requires Node.js. Free to use. Works with any MCP-compatible AI assistant (Claude, Cursor, etc.).
