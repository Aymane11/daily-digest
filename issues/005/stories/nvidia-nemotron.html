MODEL OPEN SOURCE

Nvidia Nemotron 3 Nano Omni

Open multimodal AI model for unified agent development

BY · NVIDIA · 4 MIN READ

★ WHAT IT DOES

Nemotron 3 Nano Omni is an open multimodal AI model that combines vision, audio, and language capabilities into a single framework. Designed to simplify development of agent-based systems, it was introduced at Nvidia GTC 2026 on April 28.

¶ 01 WHY TRY IT

This is Nvidia's first open multimodal model designed specifically for agent workflows. If you're building AI agents that need to process images, audio, and text, this could reduce the complexity of your stack.

¶ 02 WHAT · TO · OBSERVE

Check the model's performance on multimodal benchmarks, particularly agent task completion rates. Evaluate whether the vision+audio+text combination meets your agent's requirements versus using separate models.

HANDS-ON · TRY IT

1. Download from Nvidia NGC or Hugging Face

2. Run with Nvidia GPU (24GB+ recommended):

python -m torchrun --nproc=1 deploy.py \
  --model-path nemotron-nano-omni

3. Test with multimodal input (image + text)

ACCESS · NOTES

Free to use. Requires Nvidia GPU with 24GB+ VRAM. Available via Nvidia NGC registry and Hugging Face. Commercial use allowed under Nvidia AI Enterprise license.
