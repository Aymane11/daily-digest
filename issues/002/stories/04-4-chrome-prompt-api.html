Chrome Prompt API

What it is: A JavaScript API in Chrome 138+ that runs Gemini Nano on-device. No server, no API key, no data leaves the machine. Supports text, image, and audio input with streaming output.

Problem it solves: Adding AI features to a web app normally requires a server-side API call, API key management, latency, and per-call cost. The Prompt API moves all of that to the user’s local hardware for users on qualifying devices.

REQUIREMENTS & COST

Chrome: 138+, desktop only
Storage: 22 GB free
GPU path: 4 GB+ VRAM
CPU path: 16 GB RAM, 4+ cores

Cost: $0. No API key. One-time model download on first use (requires unmetered connection).

Copy-paste quickstart

1. Enable the flag in Chrome 138+

chrome://flags → search "Prompt API" → enable
# then relaunch Chrome

2. Check availability and create a session (DevTools console)

const avail = await LanguageModel.availability({
  expectedInputs: [{ type: 'text', languages: ['en'] }],
  expectedOutputs: [{ type: 'text', languages: ['en'] }]
});
console.log(avail); // "readily" = ready, "downloading" = model loading

const session = await LanguageModel.create();
console.log(`Context: ${session.contextUsage}/${session.contextWindow} tokens`);

3. Simple prompt

const result = await session.prompt(
  'Summarize this text in one sentence: ' + document.body.innerText.slice(0, 2000)
);
console.log(result);

4. Streaming response

const output = document.getElementById('output');
const stream = session.promptStreaming('Explain this page step by step:');
for await (const chunk of stream) {
  output.innerText += chunk;
}

5. JSON schema-constrained output

const schema = {
  type: "object",
  properties: {
    category: { type: "string", enum: ["tech", "sports", "finance", "other"] },
    confidence: { type: "number" }
  }
};
const result = await session.prompt(
  'Classify this article: ' + articleText,
  { responseConstraint: schema }
);
const parsed = JSON.parse(result); // guaranteed valid against schema

WHAT TO OBSERVE

After calling LanguageModel.create(), open Activity Monitor (macOS) or Task Manager (Windows) and verify no outbound network connections spike. All inference should run locally—network activity means the model is still downloading, not that inference is cloud-side.

Test the JSON schema constraint: send a prompt that would naturally produce free-form text and verify the output parses correctly against your schema. Constraint satisfaction is the distinguishing feature for structured classification tasks.

PAID ALTERNATIVE FOR UNSUPPORTED HARDWARE

If your users’ hardware does not meet the requirements, fall back to a small cloud model: Gemini Flash, Claude Haiku 4.5, or GPT-4o-mini are all low-cost options for the same classification/summarization tasks at <$0.01/M tokens.
