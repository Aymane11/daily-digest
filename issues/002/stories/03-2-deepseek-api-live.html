MODELS API

DeepSeek V4 API is live, supports both OpenAI and Anthropic API formats at $0.14/M tokens

TL;DR — The DeepSeek V4-Pro API is available now at api.deepseek.com. Drop-in compatible with both the OpenAI ChatCompletions API and the Anthropic Messages API. Input: $0.14/M tokens. Output: $0.56/M tokens. Supports 1M-token context window.

MON 27 APR 2026 · 2 MIN READ · SOURCE: API-DOCS.DEEPSEEK.COM

The DeepSeek V4 API launched alongside the model release on April 24, 2026. V4-Pro (1.6T params, 49B active) and V4-Flash (284B params, 13B active) are both available. The API accepts requests in the OpenAI ChatCompletions format and the Anthropic Messages format interchangeably—switching from either provider is a base URL change and an API key swap.

# OpenAI-compatible (change base_url only)
from openai import OpenAI
client = OpenAI(
    api_key="your-deepseek-key",
    base_url="https://api.deepseek.com/v1"
)
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "Hello"}]
)

Pricing: V4-Pro at $0.14/M input tokens and $0.56/M output tokens. For comparison, Claude Opus 4.6 costs $1.50/M input; GPT-5.4 costs approximately $2/M input. At similar SWE-bench Verified performance (V4-Pro: 80.6%, Opus 4.6: 80.8%), V4-Pro represents roughly a 10× cost reduction for coding workloads.

WHAT TO WATCH

Try swapping your current API endpoint to DeepSeek V4-Pro on a non-critical coding task today. The base URL change takes under a minute. Evaluate output quality on your specific use case before committing—benchmark numbers do not always translate directly to your workload.
