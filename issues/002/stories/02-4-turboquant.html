ML / INFRA QUANTIZATION

TurboQuant compresses KV-cache vectors to 2–4 bits with near-Shannon fidelity

TL;DR — TurboQuant applies a single fixed random rotation to any input vector, turning it into a vector whose coordinates follow a known distribution. A universal Lloyd–Max codebook then quantizes it to 2–4 bits with MSE within 1.45× of Shannon’s minimum at 1 bit. On Llama-3.1-8B, 4× KV cache compression matches full-precision Needle-in-Haystack recall (0.997 vs 0.997).

MON 27 APR 2026 · 4 MIN READ · SOURCE: ARKAUNG.GITHUB.IO · HN 158 PTS

¶01 — What happened

TurboQuant is a vector quantization method that compresses high-dimensional vectors—KV caches, embeddings, attention keys—to 2–4 bits per coordinate while maintaining near-optimal reconstruction fidelity. It appeared as an interactive walkthrough on Hacker News and gathered 158 points.

The core idea: apply a fixed random orthogonal rotation matrix to any input vector. In high dimensions, this rotation distributes concentrated magnitude evenly across all coordinates. The resulting rotated vector follows a known, fixed distribution (converging to Gaussian as dimensions grow). A single universal Lloyd–Max codebook, designed once for this distribution, can then optimally quantize any vector—with no per-block metadata, no calibration data, and no training.

Existing quantization methods require per-block scale factors and zero-points—32 bits of overhead per small block—which effectively doubles the real bit rate at low precision. TurboQuant eliminates this overhead entirely: one scalar per vector (residual norm in the unbiased variant).

THE ALGORITHM IN 4 STEPS

1 — ROTATE

Multiply input vector by a fixed random orthogonal matrix Π. This distributes concentrated magnitude evenly.

2 — CODEBOOK

Each coordinate now follows a known Beta/Gaussian distribution. A Lloyd–Max codebook designed for this distribution is optimal.

3 — QUANTIZE

Snap each rotated coordinate to the nearest codebook entry. This is a table lookup—no multiplications.

4 — DECODE

Multiply the quantized vector by Π¹ (transposed) to recover the approximate original. No per-block metadata needed.

¶02 — Why it matters

KV cache is the primary memory bottleneck for long-context inference. A 1M-token context in a large model can require hundreds of gigabytes of KV cache if stored at full precision. 4× compression via TurboQuant brings that to tens of gigabytes—the difference between needing a server cluster and a single high-memory GPU.

On Llama-3.1-8B, 4-bit TurboQuant achieves 0.997 Needle-in-Haystack recall versus 0.997 at full precision—statistically identical. Vector search encoding runs 4–6 orders of magnitude faster than alternatives (milliseconds vs hours on 100K vectors) because quantization is rotation plus table lookup with no learned parameters.

The method requires no training data and no calibration. A fixed random rotation matrix and precomputed codebooks are the only prerequisites—both are pure math, not model-dependent artifacts.

¶03 — What to watch

WHAT TO WATCH

Watch for integration into vLLM and llama.cpp—the logical next step once the method gains wider attention. The zero-calibration property makes it a drop-in candidate for any inference serving stack.
