OPEN SOURCE AGENTS

Block donates Goose—a Rust, local-first AI agent with MCP support—to the Linux Foundation

TL;DR — Block (formerly Square) open-sourced its internal AI coding agent Goose and donated it to the Linux Foundation’s Agentic AI Foundation. Written in Rust, runs fully locally, supports MCP, and works with any LLM backend. 4,900+ GitHub stars since open-sourcing.

MON 27 APR 2026 · 2 MIN READ

Block donated Goose to the Linux Foundation’s Agentic AI Foundation, placing it under the same neutral governance umbrella as MCP. Goose is a local-first AI agent framework written in Rust: it runs entirely on your machine, connects to external tools through MCP, and supports any LLM backend that exposes an OpenAI-compatible or Anthropic-compatible API.

The Rust implementation means Goose runs efficiently on laptop hardware without a GPU requirement. The local-first architecture means no agent actions or context leave your machine unless you explicitly configure an external API. For teams with data-residency requirements or security constraints on using cloud AI services, Goose paired with a local model (Llama, DeepSeek V4-Flash) represents a fully on-premises agentic coding stack.

The project gained 4,900+ GitHub stars since open-sourcing. The Linux Foundation donation signals Block’s intent to build an ecosystem around it rather than treating it as a competitive moat.

WHAT TO WATCH

Try Goose locally if you need an agent that stays on your machine. Install from github.com/block/goose, configure it with your preferred LLM backend, and run it against a local codebase task. Evaluate whether the local-first constraint is a tradeoff or a requirement for your use case.
