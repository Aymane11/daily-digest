DeepSeek V4 ships 1.6T-parameter open model with 1M-token context and MIT license

TL;DR — DeepSeek-V4-Pro is a 1.6T-parameter MoE model, 49B active params per token, 1M-token context, MIT licensed, API at $0.14/M input tokens. It achieves 80.6% on SWE-bench Verified—within 0.2 points of Claude Opus 4.6—at roughly one-tenth the inference cost.

MON 27 APR 2026 · 4 MIN READ · SOURCE: API-DOCS.DEEPSEEK.COM

¶01 — What happened

On April 24, 2026, DeepSeek released a two-model family under the MIT License. V4-Pro is a 1.6 trillion-parameter Mixture-of-Experts model that activates only 49 billion parameters per token—comparable compute per call to a 50B dense model, but with the capacity of a much larger system. V4-Flash is the lighter variant: 284B total, 13B active, intended for latency-sensitive applications.

Both models support a 1 million-token context window. In the 1M-token configuration, V4-Pro requires only 27% of single-token inference FLOPs and 10% of KV cache versus DeepSeek V3.2—achieved through architectural changes to attention and routing that the team calls “efficient long-context MoE”.

The API is live at api-docs.deepseek.com with compatibility for both OpenAI ChatCompletions and Anthropic API formats, making migration a drop-in change for most codebases. Pricing: $0.14/M input tokens, $0.56/M output tokens for V4-Pro.

¶02 — Why it matters

V4-Pro scores 80.6% on SWE-bench Verified, within 0.2 points of Claude Opus 4.6 (80.8%) and ahead of GPT-5.4 on the same benchmark. On the Putnam-2025 math competition benchmark, V4 reaches a proof-perfect 120/120. In coding competitions, DeepSeek rates V4 performance as “comparable to GPT-5.4”.

The MIT license means V4 weights can be used commercially, fine-tuned, and redistributed without restriction. For teams currently spending on frontier APIs for coding tasks, V4-Pro at $0.14/M tokens represents roughly a 10× cost reduction versus Claude Opus 4.6 ($1.50/M) and GPT-5.4 ($2/M) at similar capability levels.

One gap remains: V4 trails proprietary frontier models in knowledge-intensive benchmarks by roughly 3–6 months. Teams building knowledge-retrieval or multi-domain reasoning products should run their own evals before switching.

¶03 — What to watch

WHAT TO WATCH

Try V4-Pro on your current coding workload this week using the deepseek-chat endpoint with the OpenAI-compatible format. Compare quality and latency against your existing model. The MIT license means you can self-host on your own infra if the API cost or data-residency picture changes.

Watch V4-Flash for latency-sensitive agentic loops where a smaller active parameter count matters more than peak benchmark scores.
