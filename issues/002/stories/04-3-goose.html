AGENT FREE & OPEN SOURCE

Block Goose

What it is: A local-first AI coding agent written in Rust, donated to the Linux Foundation. Supports MCP tools and any LLM backend. Runs entirely on your machine—no cloud dependency.

Problem it solves: Teams with data-residency constraints, air-gapped environments, or cost sensitivities need a capable agentic coding tool that does not require sending code to external APIs. Goose is the first production-grade agent in this category under neutral open-source governance.

ACCESS & COST

Free and open source (Apache 2.0). Costs zero if you run a local model (Ollama, llama.cpp). API costs only if you configure Goose to use a cloud LLM backend—those are billed by the model provider, not by Goose.

Copy-paste quickstart

1. Install Goose (macOS / Linux)

curl -fsSL https://github.com/block/goose/releases/latest/download/install.sh | bash

2. Configure a local model backend (Ollama example)

# First install Ollama and pull a model
ollama pull deepseek-r1:7b

# Configure Goose to use it
goose configure --provider ollama --model deepseek-r1:7b

3. Or configure a cloud backend (Anthropic example)

export ANTHROPIC_API_KEY="your-key"
goose configure --provider anthropic --model claude-sonnet-4-6

4. Run Goose on a task

cd your-project
goose run "Add input validation to the POST /users endpoint and write tests for it"

5. Add an MCP server for additional tools

# goose.yaml
extensions:
  - name: filesystem
    type: mcp
    server: "npx @modelcontextprotocol/server-filesystem /your/project"

WHAT TO OBSERVE

After running a task, check the diff with git diff. Verify Goose touched only the files relevant to the task. If it modified unrelated files or accessed resources outside the project directory, that signals a scope issue in your instructions or tool configuration.

Confirm that with a local model backend, goose run produces no outbound network traffic to AI providers (check with lsof -i or a network monitor). That confirms the local-first guarantee is actually in effect.
