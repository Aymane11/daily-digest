Chrome ships Prompt API: Gemini Nano runs in-browser with no server calls

TL;DR — Chrome 138+ exposes a LanguageModel JavaScript API backed by Gemini Nano running fully on-device. Supports text, image, and audio input. Requires 22 GB storage and 4 GB VRAM or 16 GB RAM. Still in origin trial as of April 2026.

MON 27 APR 2026 · 3 MIN READ · SOURCE: DEVELOPER.CHROME.COM

¶01 — What happened

Google shipped the Prompt API for Chrome 138+, allowing web developers to send natural-language requests directly to Gemini Nano running on the user’s device. No API key, no server round-trip, no data leaves the machine. The API is available today on localhost with a flag, and via origin trial for production deployments.

The LanguageModel global exposes availability(), create(), and prompt() / promptStreaming(). Sessions maintain conversation context up to a token limit and emit a contextoverflow event when exceeded. JSON schema-constrained output is supported via responseConstraint.

// check availability first
const avail = await LanguageModel.availability({
  expectedInputs: [{ type: 'text', languages: ['en'] }]
});

// create a session
const session = await LanguageModel.create();

// simple prompt
const result = await session.prompt('Summarize this page.');
console.log(result);

// streaming
const stream = session.promptStreaming('Explain step by step:');
for await (const chunk of stream) {
  document.body.innerText += chunk;
}

¶02 — Why it matters

On-device inference removes the two main barriers to building AI features into web apps: API cost and data privacy. A content filter, smart search, or classification feature that runs locally costs nothing per call and never exposes user data to a server. For regulated industries (healthcare, legal, finance) this matters enormously.

The hardware requirements are a real constraint today: 22 GB storage, plus either a 4 GB VRAM GPU or 16 GB RAM CPU. That covers high-end laptops and desktops well, but excludes most mobile devices and low-end hardware. On Chromebook Plus the API is available directly; on standard Chromebooks it is not.

The model is Gemini Nano, a significantly smaller model than Gemini Pro or Ultra. Expect it to handle summarization, classification, extraction, and short-form generation well; do not expect complex multi-step reasoning or code generation at the level of frontier APIs.

¶03 — What to watch

WHAT TO WATCH

Try the API today: open Chrome 138+ on desktop, navigate to chrome://flags, enable #prompt-api-for-gemini-nano, then run the snippet above in DevTools console to confirm your hardware qualifies.

Watch for the origin trial window—currently limited to Chrome 138+. When the API graduates to stable it will become available to all Chrome users meeting the hardware bar, which represents hundreds of millions of potential zero-cost inference endpoints.
