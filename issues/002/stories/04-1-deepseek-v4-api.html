DeepSeek V4 API

What it is: REST API for DeepSeek-V4-Pro and V4-Flash—MoE models with 1M-token context that match Claude Opus 4.6 SWE-bench scores at ~10× lower cost.

Problem it solves: Frontier-quality coding and reasoning at a price point that makes high-volume agentic workloads economically viable ($0.14/M vs $1.50/M input tokens).

PRICING

V4-Pro input
$0.14/M tokens
V4-Pro output
$0.56/M tokens
V4-Flash
Lower — see docs

Free tier: limited daily quota available without payment method on first signup.

Copy-paste quickstart

1. Get an API key at platform.deepseek.com

export DEEPSEEK_API_KEY="your-key-here"

2. Install the OpenAI SDK (no DeepSeek-specific SDK needed)

pip install openai

3. Send your first request

from openai import OpenAI
import os

client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",        # V4-Pro
    # model="deepseek-flash",     # V4-Flash (faster, cheaper)
    messages=[
        {"role": "system", "content": "You are a senior software engineer."},
        {"role": "user",   "content": "Review this function for bugs: ..."}
    ],
    max_tokens=1024
)
print(response.choices[0].message.content)

4. For 1M-token context (large codebase ingestion)

# Same as above — V4-Pro supports 1M tokens natively.
# Pass your entire codebase as context; no chunking required
# for repos under ~750K tokens (leaving room for the response).

WHAT TO OBSERVE

On a coding task: compare the reasoning quality in the response to your current model. V4-Pro should produce comparable output on code generation and review. If you see regressions on knowledge-heavy questions (domain-specific APIs, niche libraries), that is expected—V4 trails frontier models on knowledge benchmarks by ~3–6 months.

On a 1M-context task: pass a large file tree and ask a question that requires cross-file reasoning. Verify the model correctly uses context from multiple files rather than hallucinating.

FREE ALTERNATIVE

Self-host DeepSeek V4-Pro weights (MIT licensed) via Ollama or vLLM on hardware with sufficient VRAM. Weights available at huggingface.co/deepseek-ai/DeepSeek-V4-Pro.
