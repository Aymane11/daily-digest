ENGINEERING DEV TOOLS

"If I could make my own GitHub" — a practitioner's critique of the modern code forge

Mat Duggan argues for JJ as the VCS layer, Gerrit-style code review, stacked PRs as first-class primitives, and a lightweight forge that runs on a Raspberry Pi — and names the alternatives that already do parts of this today.

BY · MAT DUGGAN · 3 MIN READ

★ WHAT HAPPENED

Mat Duggan published a detailed essay critiquing GitHub's accumulated design debt and outlining what a better code forge would look like in 2026. The piece is concrete rather than abstract: it names Jujutsu (JJ) as a better VCS alternative to Git for the underlying operations layer, argues for Gerrit's change-based review model over GitHub's PR model, calls for stacked pull requests as a first-class feature rather than a workaround, and asks for a forge light enough to self-host on commodity hardware. The essay also evaluates existing alternatives — Forgejo, Gitea, Phabricator, Radicle — on each dimension.

¶ 01 WHY · IT · MATTERS

The pull-request model shapes how teams structure work: because GitHub PRs are atomic "done or not done" units, engineers avoid small incremental commits and instead batch large changes — the opposite of what continuous integration requires. The critique has real operational weight as AI-assisted development produces higher code volume: review processes designed for human-paced output are visibly buckling. Duggan's point about self-hostability is also newly urgent given that GitHub outages and Microsoft policy decisions are now operational risks for the organisations that host critical infrastructure there.

¶ 02 WHAT · TO · WATCH

Read the full engineering deep-dive at the link below — it includes a practical comparison table of current forges against each stated requirement. Try Jujutsu for a week on a personal project before adopting it at team scale; the mental model shift from Git branches to JJ's change-centric model is non-trivial. Evaluate whether stacked PRs via gh stack or Graphite would address your team's specific bottleneck before committing to a full forge migration.
