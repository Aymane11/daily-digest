★ WHAT IT IS

Grok 4.3 is xAI's latest API model, released April 30, 2026. It is the same architecture as Grok 4.2 with an improved training recipe — no parameter count increase. Input costs $1.25 per million tokens; output costs $2.50. The context window is 131K tokens. The model scores 53 on Artificial Analysis's Intelligence Index, placing it in the same tier as Claude Sonnet 4.5. Access is available immediately via the x.ai/api endpoint with no waitlist. The model is closed-weight and hosted exclusively by xAI — no self-hosting option.

¶ 01 WHY · IT · MATTERS

At $2.50/M output tokens, Grok 4.3 undercuts GPT-4o mini on output pricing while sitting significantly above it on benchmark performance. For high-output workflows — document generation, code completion at scale, batch classification — this creates a meaningful cost advantage over both GPT-4o and Claude Sonnet. The price also forces a direct comparison question for any team currently routing high-volume traffic to a more expensive model: is the quality difference worth 2–5× the per-token cost? The answer will vary by task, but the question is now worth running.

¶ 02 HOW · TO · TRY · IT ~15 MIN
01

Create an account at x.ai/api and generate an API key. The endpoint is OpenAI-compatible — you can swap the base URL in your existing OpenAI SDK setup without changing any other code.

02

Take one of your highest-volume production prompts — the kind you run thousands of times a week — and run it through Grok 4.3 with the same temperature and system prompt settings you use in production.

03

Score 20 outputs blind: shuffle Grok 4.3 and your current model's outputs, label them A/B without revealing which is which, and rate each on your internal quality rubric. Calculate whether the quality difference, if any, is worth the price difference.

¶ 03 WHAT · TO · OBSERVE

Check instruction-following precision specifically: xAI models have historically been more permissive about safety refusals but occasionally more literal about format requirements, which can break structured-output pipelines. Test any JSON-mode or tool-call-format prompts explicitly before routing production traffic. Note latency at your peak throughput level — Grok 4.3 is hosted only on xAI infrastructure and has not yet been stress-tested at OpenAI/Anthropic scale volumes. Confirm whether the xAI API terms allow the use cases in your application before committing to a migration.
