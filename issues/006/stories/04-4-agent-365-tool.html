Microsoft Agent 365

$15/user/month standalone. GA May 1, 2026. 10M+ agents already registered.

Microsoft's enterprise agentic platform goes generally available today, bundled into the new M365 E7 tier — the first new enterprise tier since E5 launched in 2015.

GA · MAY 1 2026 · MICROSOFT

★ WHAT IT IS

Microsoft Agent 365 is an enterprise agentic platform that allows organisations to build, deploy, and manage AI agents that operate across Microsoft 365 applications — Teams, Outlook, SharePoint, and Power Platform. It reaches general availability on May 1, 2026. Standalone pricing is $15 per user per month. It is also the first component of the new M365 E7 tier, which bundles E5, Copilot for Microsoft 365, Entra Suite, and Agent 365 at $99 per user per month. More than 10 million agents have already been registered during the preview period. The platform includes governance tools for agent audit trails, access controls, and compliance monitoring.

¶ 01 WHY · IT · MATTERS

E7 is the first new enterprise Microsoft 365 tier since E5 launched in 2015. The 10-year gap and the bundling strategy signal that Microsoft views agentic AI as the successor category to productivity software, not an add-on. For enterprise IT buyers, the E7 bundle creates a familiar procurement pattern: consolidate onto the Microsoft stack and get AI governance built in. For competing platforms — Salesforce, ServiceNow, Google Workspace — this is a direct competitive move into their workflow automation territory. The $15 standalone price sets a market reference point for enterprise agent platforms.

¶ 02 HOW · TO · TRY · IT ~25 MIN
01

If your organisation has an existing M365 E3 or E5 licence, check whether the Agent 365 trial has been auto-enabled for your tenant via the Microsoft 365 Admin Centre. Navigate to admin.microsoft.com → Billing → Purchase services and look for Agent 365.

02

Open Microsoft Copilot Studio and create a simple agent: pick a SharePoint site as a knowledge source, set a system prompt describing the agent's purpose (e.g. "Answer questions about the employee handbook"), and publish it to Teams.

03

Ask the agent three questions that require cross-referencing multiple documents in the SharePoint source. Evaluate: does it cite sources, does it hallucinate content not present in the source, and does the answer quality justify the per-user cost for your specific use case?

¶ 03 WHAT · TO · OBSERVE

Review the agent audit log in the Admin Centre: every action taken by a deployed agent should appear there with user attribution. If it doesn't, that's a governance gap your compliance team needs to know about before broad deployment. Check the data residency settings — Agent 365 will by default process data in Microsoft's standard regional data centres, not necessarily your organisation's compliance boundary. Evaluate whether the E7 bundle pricing genuinely saves money versus your current M365 tier plus a third-party automation tool, or whether you're being moved into a bundle that includes capabilities you won't use.
