AI POLICY OPEN SOURCE SECURITY

Anthropic has built a keyword trigger into Claude Code that exhausts a user's session quota when the tool reads git commit messages referencing "OpenClaw" — the open-source CLI alternative that Anthropic restricted from OAuth access in April 2026.

¶ 01 WHAT · HAPPENED

Developer Theo documented the behaviour on 30 April 2026: when Claude Code processes a repository whose git history contains the string "openclaw" — even in JSON blobs or variable names — the session disconnects and reports 100% usage exhausted. Affected users saw charges appear despite minimal actual compute work. Reproductions confirmed the pattern is consistent. Whether the detection is regex-based or LLM-driven remains unclear from available evidence; community testing found no obvious way to spoof or suppress the trigger short of rewriting commit history.

¶ 02 WHY · IT · MATTERS

The incident surfaces two distinct problems. First, it is a competition-enforcement mechanism embedded in a developer tool. Anthropic banned third-party OAuth usage of its subscription tokens in April 2026, but a quota-drain triggered by a competitor's name in a commit message goes further — it penalises developers for having worked with or documented an alternative tool. Second, it creates a denial-of-service vector: any hostile open-source project could embed the trigger string in its commit messages, README, or configuration, silently wrecking a Claude Code user's session. Multiple HN commenters immediately noted this attack surface. The implementation was widely criticised as "vibe coded" — implemented without considering obvious false-positive scenarios such as a developer documenting migration away from OpenClaw.

¶ 03 WHAT · TO · WATCH

Check your own repositories for the trigger before starting a Claude Code session on any project with external contributors: run git log --all --oneline | grep -i openclaw to see if any commit mentions the string. Watch for an official Anthropic statement — the company said nothing publicly within 24 hours of the report going viral. If Anthropic removes or limits the trigger, expect a policy announcement clarifying what keyword-based enforcement is still active. Evaluate whether your organisation's AI tool policy should include testing AI coding assistants against adversarial repository content before wider deployment.
