GPT-5.5 API

OpenAI’s most capable agentic model, now at API pricing you can run in production

$5 input / $30 output per million tokens. 84.9% GDPval. 58.6% SWE-bench Pro. Available via the Responses API and legacy Chat Completions. No free tier—requires a paid API account.

TUE 28 APR 2026 · BY EDITORIAL TEAM

★ WHAT IT IS

GPT-5.5 is OpenAI’s frontier agentic model, released via API on April 24, 2026. It is accessible through the OpenAI Responses API (OpenAI’s new preferred interface for multi-step, tool-using agents) and the legacy Chat Completions endpoint for backwards compatibility. The model posts 84.9% on GDPval and 58.6% on SWE-bench Pro—trailing Claude Opus 4.7 by 5.7 percentage points on the coding benchmark but leading on general reasoning. Pricing is $5 per million input tokens and $30 per million output tokens, with a 128K context window. No free-tier access; a paid API account is required. ChatGPT Pro subscribers can access the model in the ChatGPT interface.

¶ 01 WHY · IT · MATTERS

GPT-5.5 closes most of the gap between GPT-5.4 and Claude Opus 4.7 on coding benchmarks while holding the pricing line from its predecessor—$5/$30 is the same pricing tier as GPT-5.4, making it a drop-in performance upgrade. For teams running agentic pipelines on OpenAI infrastructure, this is a meaningful capability step without a cost regression. The Responses API endpoint is the more important change architecturally: it is OpenAI’s bet on the agentic interaction model (multi-step, tool-use-first, stateful), and GPT-5.5 is the first model to fully support it. Teams still using Chat Completions for agentic tasks should treat this release as a prompt to evaluate migrating to Responses API—OpenAI has signaled Chat Completions will remain supported but receive lower investment going forward.

¶ 02 HOW · TO · TRY · IT ~10 MIN
01

Get an API key from platform.openai.com. You need a paid account (the free tier does not include GPT-5.5). Set it as an environment variable: export OPENAI_API_KEY=sk-...

02

Install or upgrade the SDK: pip install --upgrade openai. The Responses API client is available from openai>=1.76.0.

03

Call via the Responses API: client.responses.create(model="gpt-5.5", input="..."). Or use legacy Chat Completions: client.chat.completions.create(model="gpt-5.5", messages=[...]).

04

Run an agentic coding task: give it a multi-file refactor with explicit tool calls for reading and writing files. Compare output token count and accuracy against a GPT-5.4 baseline on the same task to measure the real-world delta.

¶ 03 WHAT · TO · OBSERVE

Watch whether GPT-5.5 reduces the number of tool-call round trips versus GPT-5.4 on agentic tasks—fewer iterations at the same accuracy is the primary efficiency signal. Check whether Responses API state management (built-in context threading) actually reduces your prompt engineering burden versus manually reconstructing context in Chat Completions. Monitor your token spend over the first week: the 6× output-to-input price ratio makes verbose reasoning traces expensive—test whether setting max_output_tokens aggressively degrades quality on your specific workload. Also evaluate the 5.7pp gap to Claude Opus 4.7 on SWE-bench Pro on your own real tasks—benchmarks and production diverge, and your codebase may favor one model’s behavior.
