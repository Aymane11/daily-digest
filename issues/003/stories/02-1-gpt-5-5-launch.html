GPT-5.5 launches at $5/$30 per million tokens—unified multimodal, 84.9% on GDPval, trails Claude on SWE-bench Pro

OpenAI’s first fully end-to-end multimodal model processes text, images, audio, and video in one architecture. API went live April 24. Effective cost increase is ~20% once token efficiency is factored in.

BY · EDITORIAL TEAM · 4 MIN

★ WHAT HAPPENED

OpenAI released GPT-5.5 on April 23, 2026, with API access following April 24. Unlike previous models that stitched together separate pipelines, GPT-5.5 processes text, images, audio, and video end-to-end in a single architecture. It replaces GPT-5.4 as the primary model in ChatGPT for Plus, Pro, Business, and Enterprise subscribers. On coding benchmarks it scores 58.6% on SWE-bench Pro—behind Claude Opus 4.7’s 64.3%—but leads on agentic tasks: 78.7% on OSWorld-Verified, 84.9% on GDPval (knowledge work across 44 occupations), and 98.0% on Tau2-bench Telecom.

¶ 01 WHY · IT · MATTERS

The unified architecture closes a real capability gap: prior multimodal models passed data between separate subsystems, introducing latency and context loss at each handoff. A true end-to-end model can reason across modalities simultaneously—relevant for any workflow that mixes documents, voice, and visual inputs. The pricing increase (input doubled from $2.50 to $5 per million tokens) is partially offset by OpenAI’s claim of higher token efficiency; the net effective increase is closer to 20% for typical workloads. On the agentic axis GPT-5.5 is the current leader; on pure code generation Claude Opus 4.7 still edges it out by 5.7 percentage points on SWE-bench Pro.

¶ 02 WHAT · TO · WATCH

Run GPT-5.5 on your heaviest agentic workflows (computer-use, multi-tool chaining, long research sessions) and measure token consumption against GPT-5.4. If output quality holds and tokens drop by 15%+, the price increase is absorbed. Evaluate the SWE-bench Pro gap: if your primary use is code generation, benchmark Claude Opus 4.7 alongside GPT-5.5 before committing to a model upgrade. Watch for OpenAI to announce Codex-specific pricing, which may differ from the base API rate.
