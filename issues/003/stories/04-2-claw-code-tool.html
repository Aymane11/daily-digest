Claw Code

Self-hostable open-source coding agent built on the Claude Code architecture

Rust core, Python workspace. Six tools: Bash, Read, Write, Edit, Glob, Grep. Multi-agent orchestration. Requires only an Anthropic API key. MIT license. 172,000+ GitHub stars in weeks.

TUE 28 APR 2026 · BY EDITORIAL TEAM

★ WHAT IT IS

Claw Code is a clean-room open-source rewrite of the Claude Code agent harness, developed by Sigrid Jin after the March 2026 Claude Code source code leak. It provides the same six core tool primitives Claude Code uses (Bash, Read, Write, Edit, Glob, Grep) plus full multi-agent orchestration and tool-calling—allowing you to run sub-agents, spawn parallel tasks, and compose complex workflows. The core binary is written in Rust for portability and performance; the workspace layer is Python for extensibility. It supports the full Anthropic tool-use API and connects directly to any Anthropic API key. The project is MIT-licensed and can be self-hosted entirely on your own infrastructure, including air-gapped environments.

¶ 01 WHY · IT · MATTERS

For teams that cannot send source code to Anthropic’s servers—regulated industries, defense contractors, any company with strict data residency requirements—Claw Code is the first production-grade agentic coding harness that runs entirely on your own infrastructure. Claude Code itself runs as a CLI that makes API calls to Anthropic; Claw Code does the same but gives you full control over the process: you can audit every line of the agent loop, modify tool behavior, add custom tools, and route API calls through your own proxy. The 172K star count in three weeks of existence signals that developer demand for a self-hostable alternative was large and unmet. The Rust core means it is genuinely portable—it can run on ARM, embedded environments, or CI systems where Node.js-based tooling is awkward.

¶ 02 HOW · TO · TRY · IT ~15 MIN
01

Verify you have Rust installed (rustc --version). If not: curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

02

Clone and build: git clone https://github.com/ultraworkers/claw-code && cd claw-code/rust && cargo build --workspace. The build takes 2–5 minutes on first run.

03

Set your Anthropic API key: export ANTHROPIC_API_KEY=sk-ant-.... Then run the doctor check: ./target/debug/claw doctor.

04

Give it a multi-file task on a non-production codebase: ./target/debug/claw "refactor all snake_case variables to camelCase in src/". Watch the tool calls in the terminal output.

¶ 03 WHAT · TO · OBSERVE

Compare Claw Code and Claude Code on the same task: same model (claude-opus-4-7 or sonnet-4-6), same prompt, same codebase. Note whether the tool-call sequences differ—Claw Code’s open-source loop may make different decisions about when to read context versus proceed. Check the build binary size and startup time; the Rust core should start significantly faster than a Node.js CLI on the same machine. Also evaluate whether the six-tool primitive set is sufficient for your actual agent workflows or whether you need to add custom tools—the Python workspace layer is where you extend it. Watch the GitHub issues for community-contributed tool implementations: the 72K forks suggest a large number of teams are already extending the tool set.
