TOOL / 04.2 FREE · OPEN SOURCE

NVIDIA Ising

The world's first open AI models for quantum processor calibration and error-correction decoding. Ising Decoding is 2.5x faster and 3x more accurate than traditional decoders. Ising Calibration is a 35B parameter VLM for automated qubit tuning.

OPEN SOURCE QUANTUM NVIDIA

WHY TRY THIS

Quantum error correction decoding is the bottleneck blocking practical fault-tolerant quantum computing. Classical decoders are accurate but too slow for real-time use; Ising Decoding closes the gap with AI acceleration. If you work on quantum hardware, simulation, or software that interfaces with quantum processors, this is the most significant new open tool in the space in 2026.

Problem it solves: the calibration and error-decoding steps that currently require manual expert tuning or slow classical algorithms, which don't scale to the qubit counts needed for useful computation.

ACCESS & PRICING

  • Free and open source — available on NVIDIA's developer platform and NGC (NVIDIA GPU Cloud)
  • Requires NVIDIA GPU for full performance; CPU inference possible for evaluation
  • No NVIDIA account required to download model weights
  • Free alternative for classical simulation: Qiskit's built-in decoders (slower, but no GPU needed)

HANDS-ON · TRY IT

Prerequisites: Python 3.10+, CUDA-capable GPU (optional but recommended)

STEP 1 — Install dependencies

pip install nvidia-ising
# Or pull from NGC:
docker pull nvcr.io/nvidia/ising:latest

STEP 2 — Run Ising Decoding on a syndrome sample

from nvidia_ising import IsingDecoder

decoder = IsingDecoder(code="surface", distance=5)
# syndrome: array of error syndrome measurements
logical_error = decoder.decode(syndrome)
print("Logical error:", logical_error)

STEP 3 — Benchmark against a classical decoder

import time

# Classical decoder (e.g., MWPM)
t0 = time.perf_counter()
classical_result = classical_decoder.decode(syndrome)
classical_ms = (time.perf_counter() - t0) * 1000

# Ising decoder
t0 = time.perf_counter()
ising_result = decoder.decode(syndrome)
ising_ms = (time.perf_counter() - t0) * 1000

print(f"Classical: {classical_ms:.1f}ms, Ising: {ising_ms:.1f}ms")
print(f"Speedup: {classical_ms/ising_ms:.1f}x")

WHAT TO OBSERVE

  • Run the benchmark above and verify you see at least 2x speedup vs. classical MWPM decoding on your syndrome size
  • Test accuracy at different error rates (physical error rate p = 0.001, 0.005, 0.01) — Ising Decoding should maintain 3x accuracy advantage across all three
  • Try Ising Calibration on simulated qubit spectroscopy data if you have access to quantum hardware data — check whether the calibration recommendations match manual expert tuning
