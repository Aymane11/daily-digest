Stripe formatted 62,213 Ruby files — 25 million lines — in a single Saturday morning using rubyfmt

ENGINEERING STRIPE OPEN SOURCE
THE BRIEF

Stripe's Developer Productivity team extended rubyfmt — a Rust-based, zero-config Ruby autoformatter — and rolled it out across the world's largest Ruby codebase in a single overnight run. The mass-format touched 62,213 files and 25 million lines. Today 100% of Stripe's Ruby code is formatted with rubyfmt, and engineers report near-invisible, frictionless enforcement with no style debates.

HOW THEY DID IT

The team used a gradual opt-in strategy first — allowing teams to enable rubyfmt file-by-file to build confidence — then validated correctness with ripper-tree diffing (parsing Ruby's AST before and after to confirm semantic equivalence). The mass-format ran on a Saturday morning to minimize merge conflicts with in-flight PRs.

The key lesson: a correctness validation step (AST diffing) was what made the organization willing to run the mass-format at all. Without it, teams wouldn't trust that reformatting 25M lines didn't silently change behavior.

WHAT TO WATCH

  • Try rubyfmt on a single Ruby project today — it's zero-config, Rust-based, and fast. Run it on a small service, review the diff, then decide if it's worth a broader rollout.
  • Check whether your team's formatting debates are costing more time than a one-time migration would — Stripe's post suggests the answer is almost always yes after the first year.
