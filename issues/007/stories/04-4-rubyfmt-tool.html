TOOL / 04.4 FREE · OPEN SOURCE

rubyfmt

Zero-config, Rust-based Ruby autoformatter — the tool Stripe used to format 25 million lines of Ruby in a single Saturday morning. Opinionated like gofmt or Prettier, with an AST-diffing correctness check that makes large-scale rollouts safe.

OPEN SOURCE RUBY DEVELOPER TOOLS

WHY TRY THIS

Ruby has historically lacked a canonical formatter — teams either ran RuboCop (configurable, slow) or had ongoing style debates. rubyfmt is the gofmt answer for Ruby: zero config, one right way, fast. Stripe's rollout proves it scales to the largest Ruby codebase in the world without breaking semantics.

Problem it solves: style debates in PR reviews, inconsistent formatting across a codebase, and the organizational friction of adopting a formatter when teams worry it might break behavior (rubyfmt's AST diffing eliminates that worry).

ACCESS & PRICING

  • Completely free — open source, available on GitHub
  • Pre-built binaries for macOS, Linux, Windows
  • Gem install available: gem install rubyfmt
  • Free alternative: RuboCop with --autocorrect (more configurable, slower, requires a config file)

HANDS-ON · TRY IT

Prerequisites: Ruby project, macOS/Linux/Windows

STEP 1 — Install rubyfmt

# Via gem:
gem install rubyfmt

# Or download binary from GitHub releases:
# github.com/fables-tales/rubyfmt/releases

STEP 2 — Format a single file (dry run first)

# Preview what would change:
rubyfmt --check app/models/user.rb

# Apply formatting:
rubyfmt -i app/models/user.rb

STEP 3 — Format an entire directory

# Format all Ruby files in app/:
find app/ -name "*.rb" | xargs rubyfmt -i

# Or with git: format only changed files
git diff --name-only --diff-filter=d HEAD | \
  grep "\.rb$" | xargs rubyfmt -i

STEP 4 — Add to CI (enforce on PRs)

# .github/workflows/format.yml
- name: Check Ruby formatting
  run: |
    find app/ lib/ -name "*.rb" | \
      xargs rubyfmt --check
    # Exits non-zero if any file needs formatting

WHAT TO OBSERVE

  • Run on a single 200-line Ruby file and review the diff — check whether any of the formatting changes feel wrong or would trigger a style debate on your team
  • Measure the execution time: rubyfmt should format 1,000 files in under 10 seconds on a modern machine
  • Run your test suite immediately after a mass-format to confirm no semantic changes — rubyfmt's AST diffing should make this redundant, but verify once for confidence
  • Add --check to your CI pipeline and count how many existing files fail — that's your formatting debt number
